# Sub-Planner Task (depth 1)

Your iter_id context is `5.1`. When spawning sub-agents via run_agent, form their IDs as `5.1.1`, `5.1.2`, etc.

## Goal

Implement the Phase 3 closed loop components.
First, modify src/environment.py to add a 1D physical pointer. Update the step function to accept an action dictionary containing continuous acceleration 'acc' and boolean 'push'. Implement elastic collisions between the pointer and objects. Render the pointer onto the canvas.
Second, modify src/thalamus.py to implement surprise-modulated adaptive cooldown C_t. Add a trainable linear position readout 'pos_readout' from the L1 latent representation, and a mathematically clean 'compute_attended_centroid' function that extracts the spatial centroid purely from visual activations of the attended segment (no ground truth).
Third, create src/motor.py implementing the 3-layer Subsumption Motor Controller (Reflexive PD Tracking, Predictive Kinematics, Deliberate Push Perturbation) and Representation Ablation Controls (random initialization and spatial attention shuffling).
Fourth, write an integration test src/test_closed_loop.py to verify all components work together in a closed-loop simulation step. Run this test to verify the implementation.
