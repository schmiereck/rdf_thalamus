The core idea: After a fixed interaction budget (say T=500 steps), measure how well the agent has learned the mass of each object by computing the prediction error of post-collision velocities on a held-out probe window.

**Why mass prediction?**
- Mass is a *hidden* parameter that cannot be read from a single frame (unlike position or color)
- Mass is only revealed through collisions: v1' = (m1-m2)/(m1+m2) * v1 + 2*m2/(m1+m2) * v2
- To learn mass, the agent must observe (or cause) collisions with each object
- An agent that actively probes specific objects (curiosity-driven) should cause more collisions and thus learn mass faster

**Cleaner still:** The simplest valid metric that avoids the EMA confound:

**Mass Estimation Accuracy.** After T interaction steps, the agent has observed certain collision events.
