## Analysis of Current State

### The Core Problem: Distractor-Rejection for Dimension Recruitment

After 18 iterations, the Thalamus project has successfully validated:
- **Representation base** (Pillars A, B, C): non-collapsing latent prediction, dynamic dimension recruitment
- **Thalamic gating** (Pillar D): attention-token routing
- **Motor control** (Pillar E): CLTS active probing
- **Non-parametric spatial bottlenecks** (Arm F): soft-argmax projection
- **WUP-MDL** (Phase 16): solves predictor cold-start, achieves 100% genuine recruitment

**The unsolved problem**: No gating mechanism can reject Noisy-TV distractors while accepting genuine objects. Three distinct cold-start pathologies have been identified and each approach has failed:

| Approach | Pathology | Mechanism | Result |
|----------|-----------|-----------|--------|
| ESUG (Phase 17) | Encoder cold-start | Random encoder projections → rough temporal dynamics (λ~1.0-1.5) → gate rejects genuine objects | Falsified |
| PVU (Phase 16) | Physical correlation | 1D physics creates high cross-dimension correlation → gate rejects everything | Falsified |
| EG-MDL (Phase 18) | Optimization transient | Cold predictor adapts rapidly → ρ = E_late/E_early → ~0 for ALL signals | Falsified |

The common thread: **every approach relies on a LEARNED signal** (encoder output, predictor error trend, or MDL consistency) that is corrupted by cold-start dynamics. The optimization transient is particularly pernicious — a randomly initialized predictor can overfit to ANY signal (even pure noise) during WUP, driving ρ → 0 universally.

### Key Insight: Structural vs. Learned Discrimination

The fundamental distinction between genuine objects and Noisy-TV is **structural**, not learnable:
- **Genuine object**: produces spatially contiguous, temporally persistent pixel patterns (obeys physical laws)
- **Noisy-TV**: produces spatially scattered, temporally independent pixel patterns (random each frame)

No amount of learning can make Noisy-TV genuinely predictable — but a cold-started predictor can *overfit* to it transiently, creating a false learnability signal. The solution is to use a **structural metric that requires no learning at all**.

### Candidate: Input-Level Temporal Autocorrelation (ITAG)

For any deterministic, continuous function f and temporally structured input x(t):
- If Corr(x(t), x(t+1)) > 0 (genuine object, pixels persist), then Corr(f(x(t)), f(x(t+1))) > 0
- If Corr(x(t), x(t+1)) = 0 (Noisy-TV, independent frames), then Corr(f(x(t)), f(x(t+1))) = 0 **exactly**

This is a mathematical theorem for independent random variables. The temporal autocorrelation of the raw pixel values at positions where the new signal is located:
- **Genuine object**: pixel values at the object's position change smoothly (object persists and moves) → r ≫ 0
- **Noisy-TV**: pixel values at the noise position change randomly each frame → r ≈ 0

**This metric requires zero learning, zero warm-up, and zero prediction.** It operates entirely on the raw input stream before any encoder or predictor touches it.

### Critical Architecture Question: Where is the "surprising" signal?

To compute ITAG only at positions associated with the NEW signal (not existing objects), we need to identify which spatial positions are "surprising." Two approaches:

1. **Latent prediction error mapping**: Use the existing (already-trained) encoder's spatial prediction error map to identify surprising positions, then compute ITAG on raw pixels at those positions. The existing encoder is NOT cold-started (trained on 3 objects), so its error map is reliable.

2. **Pixel activity detection**: Simply identify positions where |pixel(x,t) - pixel(x,t-1)| is elevated compared to a running baseline. No encoder needed.

Both approaches isolate the new signal's positions and compute ITAG only there, avoiding contamination from well-predicted existing objects.

### Risk Assessment

**Primary risk**: If Noisy-TV is implemented as temporally smooth noise (e.g., Perlin noise), ITAG ≈ 0 would not hold and the metric would fail. However, the standard "Noisy-TV" definition in the curiosity literature (and consistent with Phase 6's implementation) is frame-to-frame independent pixel noise, for which ITAG ≈ 0 is exact.

**Secondary risk**: If the new object moves extremely fast (≈1 object width per frame), pixel-level temporal autocorrelation at a fixed position might be low. However, even fast-moving objects in the 1D environment span 10-20 pixels and move at moderate velocities, giving each pixel position several frames of object exposure → ITAG remains positive.

**Tertiary risk**: If existing objects' prediction errors dominate the "surprising" positions (i.e., the system hasn't converged on existing objects), the ITAG computation would be contaminated. But by Phase 4+ evaluation (after convergence), existing object error should be small.

### Complementary Metric: Spatial Autocorrelation (ISAG)

Within a single frame, adjacent pixels of a genuine object are correlated (smooth gradient edges per Section 3), while adjacent Noisy-TV pixels are independent. The lag-1 spatial autocorrelation of pixel values in the surprising region provides a complementary, frame-by-frame discriminative signal that doesn't require a temporal window.

**Combined metric STC = ITAG × ISAG**: both temporal AND spatial coherence must be present for recruitment. This provides maximum robustness.

## Phase 19 Hypothesis

**Input-Level Spatiotemporal Coherence Gating (STC-Gate)**: The temporal and spatial autocorrelation of raw pixel values at the surprising region of the 1D input provides a cold-start-immune discriminative signal for dimension recruitment gating. This metric avoids all three known cold-start pathologies because it is a structural property of the input signal, requiring no encoder output, no predictor output, and no learning during evaluation.

**Formal definition**: When overall latent prediction error exceeds the recruitment threshold:

1. **Identify surprising positions** via the existing (pre-trained) encoder's per-position prediction error: S = top-K positions by ||z(x,t) - ẑ(x,t)||
2. **ITAG** (temporal coherence): For each x ∈ S, compute r_temp(x) = Corr[pixel(x,t), pixel(x,t+1)] over W_t consecutive timesteps. ITAG = mean_{x∈S} r_temp(x)
3. **ISAG** (spatial coherence): For each frame, compute r_spat = Corr[pixel(x,t), pixel(x+1,t)] for x, x+1 ∈ S. ISAG = mean over frames of r_spat
4. **STC** = ITAG (primary gate). ISAG used as secondary confirmation.

**Gating rule**: If ITAG > τ (τ = 0.3), initiate WUP-MDL recruitment. If ITAG ≤ τ, reject the dimension proposal immediately.

**Predicted values**:
- Genuine N=3→4 transition: ITAG > 0.5, ISAG > 0.5
- Noisy-TV control: ITAG < 0.1, ISAG < 0.1

**Why this avoids all three cold-start pathologies**:
1. **Encoder cold-start**: ITAG/ISAG operate on raw pixels, not encoder output. The existing encoder's error map is used only for spatial localization (it is pre-trained, not cold).
2. **Predictor cold-start**: No predictor is needed. The metric is observational.
3. **Optimization transient**: No learning occurs during the ITAG/ISAG evaluation window. The metric is computed from raw data before any weight updates.
