## Hypothesis Formulation

The Entropy-Gated MDL (EG-MDL) framework adds a **WUP-period prediction-trend gate** to the existing WUP-MDL mechanism. The gate measures whether prediction error is actually *improving* during the warm-up period — rejecting dimensions whose prediction error does not decrease, as this indicates unmodelable stochastic input (Noisy-TV) rather than a genuine learnable object.

**Formal definition of the prediction-trend gate:**

During WUP period of W steps:
1. Record per-step prediction error `e[t]` for the proposed dimension, for `t ∈ [0, W)`
2. Compute `E_early = mean(e[0 : W/2])` and `E_late = mean(e[W/2 : W])`
3. Define the **improvement ratio**: `ρ = E_late / E_early`
4. Gate condition: `ρ < θ` where `θ ∈ (0, 1)` is the improvement threshold

**For a genuine object:** The predictor learns smooth dynamics → E_late << E_early → ρ << 1.0
**For Noisy-TV:** No learnable structure → E_late ≈ E_early → ρ ≈ 1.0

The composite EG-MDL gate requires BOTH:
- MDL criterion: `L_consistency = Var_scenarios[z_new] / Var_scenarios[z_old] < 1.0`
- Prediction-trend criterion: `ρ = E_late / E_early < θ`

I also want to test a **spatial entropy gate** as a complementary signal: genuine objects produce spatially concentrated soft-argmax attention (low entropy), while Noisy-TV produces diffuse attention (high entropy).
