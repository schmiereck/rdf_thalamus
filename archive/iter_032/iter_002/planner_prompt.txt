### Architecture Changes Required

**Modify `src/models_separate_dyn.py`** — Update `SeparateDynEncoder` to support centroid_gated readout:

1. In `__init__`, when `dyn_readout == "centroid_gated"`:
   - Replace `self.conv_identity_dyn = nn.Conv1d(128, d_max, kernel_size=1)` with `self.conv_identity_dyn = nn.Conv1d(128, d_max * sub_features, kernel_size=1)`
   - Keep all other layers the same (coord backbone unchanged)

2. In `forward()`:
   - Always compute coord backbone first (same as now), producing `a_spatial (B, d_max, 128)` and `p_c = F.softmax(a_spatial, dim=-1)`
   - For dyn backbone, produce `dyn_features (B, 128, 8)` then `a_dyn = self.conv_identity_dyn(dyn_features)` producing either `(B, d_max, 8)` or `(B, d_max*K, 8)` depending on sub_features
   - Implement three readout modes:
     a. `dyn_readout == "mean"` (existing): `z_dyn = a_dyn.mean(dim=-1)` → (B, d_max)  [unchanged]
     b. `dyn_readout == "centroid_gated"` with `sub_features == 1`:
        - Interpolate a_dyn from 8 to 128: `a_dyn_128 = F.interpolate(a_dyn, size=128, mode='linear', align_corners=False)` → (B, d_max, 128)
        - `z_dyn = torch.einsum('bcs,bs->bc', p_c.detach(), a_dyn_128)` → (B, d_max)
     c. `dyn_readout == "centroid_gated"` with `sub_features > 1`:
        - Interpolate a_dyn from 8 to 128: `a_dyn_128 = F.interpolate(a_dyn, size=128, mode='linear', align_corners=False)` → (B, d_max*K, 128)
        - Reshape: `a_dyn_128 = a_dyn_128.reshape(B, d_max, K, 128)` where K = sub_features
        - `z_dyn = torch.einsum('bcs,bcks->bck', p_c.detach(), a_dyn_128)` → (B, d_max, K)
        - Reshape: `z_dyn = z_dyn.reshape(B, d_max * K)` → (B, d_max*K)
   
   STOP-GRADIENT on p_c is critical (consistent with existing centroid_gated convention) — the coord backbone's attention weights should not receive gradient from the dyn readout.

3. The `d_dyn` property should return `d_max * self.sub_features` (already exists, verify it works with the new readout).

4. **NonParametricJEPASpatialSeparateDyn** must also be updated:
   - Ensure it correctly passes `dyn_readout` and `sub_features` to the encoder
   - Ensure `self.sub_features` is accessible on the model for evaluation
   - The clone() method must also pass these parameters
   - Make sure the model's `forward()` correctly handles the different d_dyn dimensions for the predictor
